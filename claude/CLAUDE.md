## Communication Style
Reply length and language (ASD-STE100) live in the output style `~/.claude/output-styles/elera-concise.md`.

- Back up claims about code with a `file:line` reference I can click. Show a code excerpt only when the claim depends on the exact code, or when I ask.
- **Show, don't only tell.** When a diagram or artifact makes an answer clearer (flows, architecture, state, comparisons, sequences, data shapes), include one: an ASCII/Mermaid diagram inline in the terminal for small cases, or a published Artifact for larger or interactive ones. Do not add a diagram when it gives no extra clarity.
